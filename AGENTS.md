# TradeBo project direction

Read [docs/PRODUCT_GOAL.md](docs/PRODUCT_GOAL.md) when planning product work. The agreed product is a strategy research platform. Keep that goal and its priority order stable unless the user changes the direction.

Prioritize correct comparisons, reproducible evaluations, and evidence quality before adding strategy families. A method losing to a baseline is a valid research result; do not tune examples merely to make them win. Keep software correctness separate from evidence of investment performance.

Keep the README concise. Put formulas, validation evidence, and implementation details in the linked documentation. Follow [CONTRIBUTING.md](CONTRIBUTING.md) for applicable checks, and update the calculation version when its contract changes.
